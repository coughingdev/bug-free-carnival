# Dino Rail Blaster – Modern Phone Adaptive Build

This version is designed for modern iPhone and Android phones in landscape.

## Responsive behavior
- Uses the real visible browser viewport, including mobile browser UI changes.
- Respects notch / Dynamic Island / punch-hole safe areas where exposed by the browser.
- Large transparent circular ↑ and ↓ controls on normal modern phones.
- Automatically shrinks controls, HUD, start button, and game-over text on short/smaller phone screens.
- Prevents pinch zoom, accidental page scrolling, and the post-loss corner-zoom issue.
- Keeps the game world at 500 units high and adjusts width to the actual phone aspect ratio, avoiding stretched graphics.
